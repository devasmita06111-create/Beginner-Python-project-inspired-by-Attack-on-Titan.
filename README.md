Attack on Titan Report Card Generator

A beginner Python project inspired by Attack on Titan.

Features

- Takes marks as input
- Calculates total marks
- Calculates percentage
- Shows grade
- Displays pass/fail result

Technologies Used

- Python

How to Run

python report_card.py

Sample Output

Tamil: 90
English: 85
Maths: 95
Biology: 88
Physics: 91
Chemistry: 89

Total: 538
Percentage: 89.67%
Grade: A
